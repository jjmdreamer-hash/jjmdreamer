# ChatGPT 이미지 프롬프트 (크롬 → chatgpt.com)

## 사용법
1. ChatGPT에서 **새 채팅 하나를 열고 에피소드 하나는 끝까지 그 채팅에서만** 만듭니다. 그래야 인물 얼굴과 그림체가 유지됩니다.
2. 맨 먼저 아래 **① 스타일 고정**을 붙여넣습니다.
3. **② 인물 시트**를 만든 다음, 결과가 마음에 들면 "이 인물들 얼굴 그대로 유지해줘"라고 말합니다.
4. **③ 장면 프롬프트**를 한 줄씩 붙여넣습니다. 한 번에 1장씩 만드세요.
5. 비율은 영상용 **16:9 가로**, 썸네일도 16:9입니다.
6. 이상하게 나오면 "같은 장면, 손가락이랑 얼굴만 자연스럽게 다시"처럼 고칠 부분만 말합니다.

> 팁: 그림에 글자가 들어가면 깨지는 경우가 많습니다. 장면 그림에는 글자를 넣지 말고,
> 썸네일 글씨는 캔바나 Vrew에서 따로 얹으세요.

---

## ① 스타일 고정 (채팅 시작할 때 1번만)
```
지금부터 조선시대 야담 오디오북 영상에 쓸 그림을 여러 장 만들 거야. 모든 그림은 아래 스타일을 똑같이 지켜줘.
- 그림체: 따뜻한 한국 전통 수묵담채화 느낌의 디지털 일러스트, 부드러운 붓 터치, 한지 질감
- 색감: 차분한 흙색, 먹색, 바랜 쪽빛, 은은한 노을빛. 채도 낮게
- 조명: 은은하고 서정적인 분위기, 잠들기 전 듣는 이야기처럼 편안하게
- 비율: 16:9 가로
- 그림 안에 글자, 자막, 워터마크는 절대 넣지 마
- 사실적인 사진 느낌이 아니라 그림 느낌으로
이해했으면 "준비됐어"라고만 답해줘.
```

## ② 인물 시트 (1화: 깨진 항아리)
```
등장인물 설정 그림을 한 장에 나란히 그려줘. 흰 배경, 전신, 정면.
1) 순덕: 20대 후반 며느리. 수수한 무명 저고리와 쪽빛 치마, 쪽진 머리, 고생한 흔적이 있지만 단정하고 선한 얼굴
2) 시어머니: 60대, 엄격하고 날카로운 눈매, 회색 저고리와 검은 치마, 은비녀, 마른 체형
3) 친정어머니: 50대 후반, 수척하고 인자한 얼굴, 낡은 흰 저고리
4) 빚쟁이 최 부자: 50대 남자, 뚱뚱한 체형, 비단 도포와 갓, 탐욕스러운 표정
```

## ④ 썸네일 프롬프트
```
같은 스타일, 같은 인물로 유튜브 썸네일용 그림. 16:9.
왼쪽에 시어머니 얼굴 클로즈업(날카로운 눈빛, 의미심장한 미소),
오른쪽에 금이 간 낡은 항아리를 두 손으로 든 순덕(당황하고 서러운 표정).
배경은 어둡게, 인물과 항아리에 강한 빛. 대비 강하게. 글자는 넣지 마.
```
썸네일 글씨는 따로 얹기: **"깨진 항아리?!"** (노랑 또는 흰색 굵은 글씨, 검은 테두리)
