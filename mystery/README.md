# 백설장 살인사건: 판매 가이드

6인용 추리게임 파티 키트(PDF)입니다. 시나리오, 디자인, 판매 페이지는 이미 완성돼 있습니다.
**사용자님은 판매처에 한 번 등록만 하면 되고,** 팔릴 때마다 추가로 할 일은 없습니다(PDF 자동 발송).

## 파일
| 파일 | 용도 |
|---|---|
| `pdf/01_진행자가이드.pdf` ~ `05_초대장.pdf` | **판매할 상품.** 5개를 zip 하나로 묶어서 올리세요 |
| `pdf/00_무료체험판.pdf` | 무료 배포용 맛보기(프롤로그와 캐릭터 1명: 서하진) |
| `../docs/mystery/index.html` | 판매 랜딩 페이지 (`BUY_URL`을 결제 링크로 바꾸기) |
| `../docs/mystery/thumb.png` | 상품 썸네일 (1000×1000) |

zip으로 묶는 명령: `cd mystery/pdf && zip ../백설장살인사건_정식판.zip 0[1-5]_*.pdf`

## 사용자님이 할 일 (처음 한 번, 30분 정도)
1. **판매처 등록.** 검색으로 손님이 알아서 들어오는 곳부터 올리세요. 개인도 판매할 수 있습니다.
   - **크몽 › 전자책/템플릿:** 심사를 통과하면 파일이 자동으로 전달됩니다.
   - **네이버 스마트스토어 › 디지털 상품(이용권/다운로드):** "추리게임", "머더미스터리", "송년회 게임"을 검색하는 사람이 들어옵니다.
   - (선택) **텀블벅:** 연말 선주문 펀딩을 열 수 있습니다. 목표 금액을 못 채우면 결제가 되지 않아 손해가 없습니다.
2. 결제 링크가 생기면 저에게 알려 주세요. 판매 페이지의 `BUY_URL`을 바꿔서 다시 올리겠습니다.
3. 무료 체험판을 보드게임·추리게임 커뮤니티(네이버 카페 등)에 **한 번** 올리세요. 각 커뮤니티의 홍보 규칙을 꼭 지키세요.

## 상품 등록용 글 (그대로 복사해서 쓰세요)

**상품명:** 백설장 살인사건 | 6인 머더미스터리 추리게임 파티 키트 PDF (송년회·집들이·워크숍)

**한 줄 소개:** 눈에 갇힌 산장, 여섯 명의 용의자. 거짓말을 할 수 있는 사람은 단 한 명뿐이다. 인쇄해서 바로 즐기는 2시간짜리 추리 파티.

**본문:**
```
12월 30일 밤, 산장 '백설장'의 송년회.
베스트셀러 작가 윤태오는 "이 자리에 거짓말쟁이가 있다"는 말을 남기고
밤 11시 30분, 서재에서 숨진 채 발견됩니다.
폭설로 길은 끊겼고, 범인은 지금 당신의 테이블에 앉아 있습니다.

■ 인원: 6명 (배역은 누구나 맡을 수 있어요)
■ 시간: 약 2시간
■ 준비: A4 인쇄 + 가위 + 봉투 4개
■ 진행자 없이도 가능 (해답은 따로 봉인된 파일)

■ 구성 (PDF)
- 진행자 가이드: 준비, 규칙, 라운드 진행표, 프롤로그 낭독문, 투표지, 점수표
- 캐릭터북 6인: 공개 소개, 비밀, 그날 밤의 진짜 행적, 개인 목표
- 단서 카드 20장: 현장 → 수색 → 재조사 3라운드
- 배역 초대장 6장
- 해답과 에필로그

■ 이런 분께 추천
연말 송년회를 술자리 말고 특별하게 보내고 싶은 분
회사 워크숍·팀빌딩 아이스브레이킹
집들이·생일파티 이벤트

※ 디지털 상품이라 다운로드 후에는 환불이 어렵습니다. 무료 체험판을 먼저 확인해 주세요.
※ 구매자 개인·모임 안에서만 인쇄할 수 있으며, 재배포와 재판매를 금합니다.
```

**검색 태그:** 머더미스터리, 추리게임, 파티게임, 송년회게임, 워크숍게임, 집들이게임, 보드게임, 마피아게임, 방탈출, 인쇄용게임

## 가격과 목표
- 정가 24,900원 → **출시 할인 19,900원**
- 판매처 수수료(크몽 약 20%, 스마트스토어 약 6%)를 빼면 한 건에 약 16,000~18,700원이 남습니다.
- **100만원까지 약 55~65건이 필요합니다.** 송년회 시즌(11~12월)이 가장 잘 팔릴 때입니다.
- 팔린다는 보장은 없습니다. 다만 제작비 0원, 재고 0개라서 **손해 볼 일은 없습니다.**

## Claude가 계속 할 일
- 후기를 보고 규칙과 단서를 고치고 PDF를 다시 빌드합니다: `cd mystery && npm install && npm run build`
- **다음 시나리오**를 만듭니다. 시리즈가 쌓이면 묶음 상품으로 가격을 올릴 수 있습니다
  (예: 8인 회사 워크숍 편, 4인 커플 편, 추석 가족 편).
- 원하시면 구매자 이름을 넣은 **맞춤 배역·초대장 버전**을 추가 요금 상품으로 만듭니다.

## ⚠️ 상품 원본은 저장소에 없습니다
이 저장소는 **공개**입니다. 누구나 공짜로 가져가지 못하도록 `content.py`(시나리오·해답 전체), `pdf/`, zip은 커밋하지 않습니다.
원본은 사용자님께 파일로 직접 전달했습니다. 안전한 곳(개인 드라이브 등)에 꼭 보관하세요.
다시 빌드하려면 `content.py`를 이 폴더에 넣고 `npm install && npm run build`를 실행하면 됩니다.
