# 루미렉소(lumirexo.com) 애드센스 승인 보완 가이드

애드센스 심사에서 거절되는 사유는 대부분 아래 네 가지입니다.

1. **가치가 별로 없는 콘텐츠**: 글이 적거나 짧음, 뉴스 요약·재작성 위주, AI 자동 생성 티가 남
2. **사이트 신뢰 정보 부족**: 소개·문의·개인정보처리방침 페이지가 없음, 운영자를 알 수 없음
3. **탐색 문제**: 메뉴가 없거나 빈 카테고리·깨진 링크·초안 URL이 노출됨
4. **정책 위반 소지**: 저작권 이미지, 선정적인 연예 가십, 제휴 링크 과다

이 폴더에는 2~3번을 바로 해결할 **붙여넣기용 페이지**와 1·4번을 점검할 **체크리스트**를 담았습니다.

## 확인한 내용 (2026-09-26)

- **사이트 직접 접속은 못 했습니다.** 작업 환경의 네트워크 정책이 `lumirexo.com`을 막고 있습니다.
  환경 설정의 Network access에 `lumirexo.com`을 추가하면 실제 글·메뉴·설정을 점검할 수 있습니다.
- **구글 검색 `site:lumirexo.com` 결과가 0건입니다.** 구글에 색인이 전혀 안 된 상태로 보입니다.
  애드센스 거절의 가장 흔한 원인이므로 2단계의 "검색 엔진 색인 차단" 설정과 서치 콘솔 등록을 **가장 먼저** 확인하세요.
- **운영 방향이 두 갈래입니다.** 프로필 페이지(정종민 · Lumirexo)는 "지원금·절세·요금제·기기 구매"
  미디어라고 소개하지만, 콘텐츠 자동화 시트의 글은 연예·기업 실적 뉴스 재작성이 많습니다.
  심사관은 사이트 소개와 실제 글이 맞는지 봅니다. 소개 페이지는 프로필 방향으로 작성했으니
  **연예·뉴스 재작성 글은 심사 기간에 비공개로 돌리는 것**을 권장합니다.
- 드라이브의 `루미렉소 콘텐츠 운영` 스킬은 ChatGPT 쪽 스킬이라 여기서는 불러올 수 없고,
  운영 안내 문서(`00_루미렉소_운영안내.md`)와 프로필 페이지 내용을 읽고 반영했습니다.

---

## 1단계: 필수 페이지 5개 만들기 (30분)

워드프레스 관리자 → 페이지 → 새로 추가 → 우측 상단 ⋮ → **코드 편집기**로 바꾸고
`pages/` 폴더의 HTML을 그대로 붙여넣습니다. 운영자 이름(정종민)과 이메일(jjmdreamer@gmail.com)은 프로필 페이지와 같게 넣어 두었습니다.

| 파일 | 페이지 제목 | 권장 주소(slug) |
|---|---|---|
| `pages/about.html` | 루미렉소 소개 | `/about` |
| `pages/contact.html` | 문의하기 | `/contact` |
| `pages/privacy.html` | 개인정보처리방침 | `/privacy-policy` |
| `pages/terms.html` | 이용약관 | `/terms` |
| `pages/disclaimer.html` | 면책 및 광고 고지 | `/disclaimer` |

- 개인정보처리방침은 **설정 → 개인정보 보호**에서 "개인정보 처리방침 페이지"로도 지정합니다.
- 문의용 이메일을 따로 두고 싶으면 `pages/contact.html`, `pages/privacy.html`의 주소만 바꾸면 됩니다.
- 다섯 페이지를 **푸터 메뉴**에 넣고, 소개·문의는 **상단 메뉴**에도 넣습니다.

## 2단계: 사이트 구조 정리

- [ ] 상단 메뉴: 홈 / 카테고리 3~5개 / 소개 / 문의
- [ ] 글이 0~1개인 카테고리는 메뉴에서 빼거나 다른 카테고리와 합치기
- [ ] "미분류(Uncategorized)" 카테고리에 글이 남아 있지 않게 하기
- [ ] 기본 "Hello world!" 글, "샘플 페이지", 테스트 글 삭제
- [ ] 글마다 작성자 이름이 `lumirexo_bot` 같은 계정명으로 보이지 않게
      사용자 → 프로필 → **"공개적으로 보일 이름"**을 `루미렉소 편집팀` 등으로 변경
- [ ] 설정 → 읽기 → **"검색 엔진이 이 사이트를 색인하지 않도록"이 꺼져 있는지** 확인 (켜져 있으면 무조건 거절)
- [ ] 설정 → 고유주소: `글 이름`(`/%postname%/`) 형식 권장
- [ ] 모바일에서 메뉴·글·푸터가 정상으로 보이는지 확인
- [ ] 404 페이지, 깨진 이미지·링크가 없는지 확인

## 3단계: 콘텐츠 기준 (가장 중요)

**신청 시점 기준 목표: 직접 가치를 더한 글 20~30개 이상, 글당 1,500자 이상.**

루미렉소는 뉴스 기사(네이버 뉴스 등)를 바탕으로 글을 만드는 구조라서, 심사에서
"기사 재작성 사이트"로 보이면 **가치가 별로 없는 콘텐츠**로 거절될 가능성이 높습니다.
아래 기준으로 기존 글을 점검하고, 미달인 글은 **비공개(초안)로 돌리거나 보강**하세요.
글 수를 채우는 것보다 부족한 글을 숨기는 편이 승인에 유리합니다.

글마다 확인할 항목:

- [ ] 원문 기사에 없는 **루미렉소만의 정보**가 있는가
      (배경 설명, 비교표, 일정 정리, 계산 예시, "그래서 독자에게 무슨 의미인가")
- [ ] 원문 문장을 순서만 바꾼 문단이 없는가
- [ ] 본문 1,500자 이상, 소제목(H2/H3) 3개 이상
- [ ] 출처 링크를 본문 하단에 표기했는가
- [ ] 이미지가 직접 만든 것이거나 사용 권한이 있는가 (기사·방송 캡처, 연예인 사진 무단 사용 금지)
- [ ] 제목이 낚시성·자극적이지 않은가 (연예 가십, 사건사고는 특히 주의)
- [ ] 같은 주제의 중복 글이 없는가
- [ ] 제휴 링크(쿠팡·토스 등)가 **없거나 최소한**인가
      심사 기간에는 제휴 링크와 다른 광고 스크립트를 빼 두는 편이 안전합니다.
- [ ] "AI가 작성했습니다" 식 문구, 반복되는 어미·템플릿 문장이 없는가

**카테고리 추천:** 연예 뉴스는 애드센스 심사와 광고 단가 모두 불리합니다.
심사 기간에는 "돈이 되는 실용정보"(지원금·세금·금융·생활 절약 등) 같은
**정보형 카테고리 글을 중심으로** 두는 것을 권장합니다.

**발행 주기:** 신청 전 2~4주 동안 하루 1~2편씩 꾸준히 발행한 기록이 있으면 좋습니다.
하루에 수십 편을 한꺼번에 올리면 자동 생성 사이트로 보일 수 있습니다.

## 4단계: 기술 설정

- [ ] **Site Kit by Google** 플러그인으로 애드센스·서치콘솔 연결 (코드 직접 삽입보다 간단)
- [ ] 구글 서치 콘솔에 사이트 등록 → 사이트맵 `https://lumirexo.com/wp-sitemap.xml` 제출
- [ ] 애드센스 신청 후 받은 게시자 ID로 `ads.txt`를 사이트 루트에 업로드 (`ads.txt` 파일 참고)
- [ ] HTTPS 정상 동작, 페이지 속도 확인 (PageSpeed Insights 모바일 50점 이상 권장)
- [ ] 쿠키/광고 관련 문구는 `pages/privacy.html`에 포함됨

## 5단계: 신청과 재신청

- 애드센스 → 사이트 → 사이트 추가 → `lumirexo.com` (www 없이) → 코드 연결 → 검토 요청
- 심사는 보통 며칠~4주 걸립니다. **심사 중에는 사이트 구조를 크게 바꾸지 말고** 글 발행은 꾸준히 이어가세요.
- 거절되면 사유를 확인하고 해당 항목만 보강한 뒤 **최소 1~2주 후** 재신청합니다.
  같은 상태로 바로 재신청하면 같은 이유로 거절됩니다.

OpenAI API 키가 그대로 적혀 있습니다.** 시트가 공유되거나 유출되면 사이트가 해킹되거나
API 요금이 청구될 수 있습니다.

1. 워드프레스 → 사용자 → `lumirexo_bot` → 애플리케이션 비밀번호에서 기존 비밀번호 **취소 후 재발급**
2. OpenAI 대시보드 → API keys에서 기존 키 **삭제 후 재발급**
3. 시트에서 두 값을 지우고, 새 값은 시트에 적지 않기 (Apps Script라면 스크립트 속성에 저장)

해킹된 사이트는 애드센스 승인도 받을 수 없으니 신청 전에 꼭 처리하세요.
