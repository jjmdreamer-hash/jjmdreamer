OMR 채점기

답안지를 출력하고, 학생 답안지를 사진으로 찍으면 바로 채점됩니다.

시험

답안지를 출력한 뒤에 문항 수나 보기 수를 바꾸면 이미 출력한 답안지는 쓸 수 없습니다. 정답과 배점은 언제든 고쳐도 됩니다.

답안지 출력

A4로 출력하세요. 인쇄 설정에서 여백 없음 또는 실제 크기를 고르면 가장 좋습니다. 매수는 인쇄 창에서 정하면 됩니다.
